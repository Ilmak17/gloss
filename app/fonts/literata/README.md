# Literata 3.103

Unmodified variable WOFF2 files from the official Google Fonts / TypeTogether release:
https://github.com/googlefonts/literata/releases/tag/3.103

- `Literata[opsz,wght].woff2` → `Literata-Roman.woff2`
- `Literata-Italic[opsz,wght].woff2` → `Literata-Italic.woff2`

Both support weight 200–900 and optical size 7–72. Regular and italic fonts include Latin, Greek and Cyrillic. Original license and copyright notices are in `OFL.txt` (SIL Open Font License 1.1).

These files are served by the reader itself. No connection to an external font CDN is required for Literata during build or reading.
